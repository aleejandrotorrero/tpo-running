# TPO. · Run your rhythm

Tienda online ficticia de running: calzado, ropa técnica, accesorios y nutrición deportiva de marcas líderes, junto a la marca propia **Tempo** (Tempo Apparel y Tempo Nutrition).

Construida a mano con HTML, CSS y JavaScript puro, sin frameworks ni librerías. Funciona como laboratorio de medición de e-commerce: todo el flujo de compra está preparado para implementar con Google Tag Manager los eventos estándar de GA4 (`view_item_list`, `view_item`, `add_to_cart`, `begin_checkout` y `purchase`).

🚧 Proyecto en construcción.

> Proyecto ficticio con fines de aprendizaje y portfolio. No se vende ningún producto.
